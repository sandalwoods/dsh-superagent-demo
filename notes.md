# Notes

This file exists so the agent has something small and safe to edit.

## Current notes

The demo repository is empty on purpose. It has no build, no tests and no dependencies, so a request produces a reviewable diff in seconds rather than after a long setup.

## Questions this repository answers

- Does the agent understand a short, explicit request?
- Does it open a pull request that a person can read and merge?
- Does it stay quiet when it has nothing useful to say?
